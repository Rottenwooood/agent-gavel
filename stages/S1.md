# S1

## 1 开头

agent-gavel 是本地浏览器运行时与 MCP server：动作带预声明断言、由程序判定成败，或录制模板后重放；当前 0.5.1。
当前阶段 S1 删除与实现脱节的文档、把陈述对齐代码，并把被跟踪代码导出为单文件代码包。
下一阶段入口：独立 benchmark（与 Playwright MCP / Stagehand / browser-use 对比），见 `docs/roadmap.md`。

## 2 计划与进度

本项目此前以版本号组织发布，`stages/` 自本阶段启用。

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| 0.1–0.4 | Playwright runtime 重建、工具面收敛前身、daemon 模型 | 完成（见 CHANGELOG） |
| 0.5.0 | 统一 diff、14 入口/89 操作、模板可编辑、导航管线收敛 | 完成 |
| 0.5.1 | `sparse_content` 只在存在附件时提示 | 完成 |
| S1 | 文档时效性收口与代码包导出（本阶段） | 完成 |
| S2 | 独立 benchmark 与观察结论 | 未开始 |

## 3 本阶段约束

- C1 只改文档陈述与已删除操作的测试调用，不动运行时与工具契约。
- C2 产物是可复用导出脚本、本阶段约束清单与仓库外的一份代码包。
- C3 文档须与代码可核对；黑盒 e2e 真实浏览器通过；代码包往返还原一致且无凭据。
- C4 只使用 uv、python、ruff、git 只读命令与本地提交、curl、node、密钥审计脚本。
- C5 不 push、不改写历史、不回滚已提交文档、不删被跟踪源码与测试。
- C6 预算 90 分钟，代码包不超过 900 KB，不调用外部模型。
