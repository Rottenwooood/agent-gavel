# S2

## 1 开头

agent-gavel 是本地浏览器运行时与 MCP server：动作带预声明断言、由程序判定成败，或录制模板后重放；当前 0.5.1。
当前阶段 S2 删除零引用函数、孤儿夹具与重叠基准，并重新生成单文件代码包。
下一阶段入口：独立 benchmark（与 Playwright MCP / Stagehand / browser-use 对比），见 `docs/roadmap.md`。

## 2 计划与进度

## 3 本阶段约束

- C1 只删零引用函数、孤儿夹具与重叠基准，不改运行时与契约。
- C2 产物是删除清单、约束清单、阶段记录与重生成的代码包。
- C3 ruff、受影响测试与真实浏览器 e2e 通过，代码包往返一致。
- C4 只使用 uv、python、pytest、ruff、git、node 与密钥审计脚本。
- C5 不 push、不改写历史、不删 legacy、不回显凭据。
- C6 预算 40 分钟，代码包不超过 900 KB。
